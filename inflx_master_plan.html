Build order — 8 steps, ~2 days

1

AgentState + graph skeleton

TypedDict with intent, collected, retrieved_context, lead_captured, turn_count. All nodes as stubs returning dummy strings. Verify graph compiles and runs end-to-end.

2

knowledge_base.json + RAG indexer

JSON with plans, policies, faqs arrays. Indexer converts to Documents, builds FAISS + MiniLM at startup. Test retrieval with 3-4 sample queries before wiring into agent.

3

Intent classifier node

Strict system prompt returning JSON: {"intent": "...", "confidence": 0.0–1.0}. Test all edge cases — "I'm interested" must map to high_intent, "how much" to inquiry. Log outputs during dev.

4

Lead collect node + router guard

State tracks collected = {}. Node asks for next missing field. Router checks all_fields_collected() before allowing execute_lead_capture. Write a test that tries to skip email — must fail.

5

FastAPI + SSE streaming endpoint

POST /chat accepts session_id + message. GET /stream/{id} returns text/event-stream. Session state persisted in-memory dict keyed by session_id. Test with curl before building UI.

6

Next.js chat UI

ChatWindow.tsx with EventSource consuming SSE. Token-by-token rendering. Intent badge shown when agent detects high_intent. LeadBadge toast fires on lead_captured: true in stream.

7

Leads dashboard + demo prep

/leads page shows table of captured leads from SQLite. Prep the exact demo script: pricing Q → intent shift → collect 3 fields → capture fires. Practice it twice before recording.

8

README + requirements.txt + .env.example

Architecture section ~200 words. WhatsApp section with actual code snippet. Embed diagram image. requirements.txt pinned versions. .env.example with placeholder keys. docker-compose optional but impactful.

Demo video script — 2.5 min, no wasted time

0:00–0:20 Show the UI cold. No intro monologue. Type "Hi, what's the difference between your plans?" — let the streaming response speak for itself.
0:20–0:50 Ask a policy question: "Can I get a refund?" — agent pulls from KB, shows source citation badge. Pause briefly, let reviewer see the RAG in action.
0:50–1:20 Type "I want to sign up for Pro for my YouTube channel." — intent badge flips to HIGH INTENT. Agent pivots to asking for name.
1:20–1:55 Collect name, email, platform across 3 turns. Show that agent remembers what it already collected — doesn't ask for name twice.
1:55–2:20 Lead capture fires. Show the green toast + confetti. Split-screen or switch tab to /leads dashboard — new row visible. Show terminal log: "Lead captured: ..."
2:20–2:30 Briefly show the graph.py and state.py in VS Code. 10 seconds. Signals clean code without narrating it.
